# 质量检查

## 已做的静态检查

- 按一天 1440 分钟逐分钟核对目标充电上限，重点覆盖 05:59、06:00、20:59、21:00、23:30。
- 检查非法时间输入，避免时间解析出错。
- 检查原生动作标识与必要参数：`limit`、`setUntilTomorrow = false`。
- 检查快捷指令源文件 plist 可解析，且每条文件只包含对应充电上限动作。
- 检查 Shell 语法、安装包目录和 ZIP 文件校验。
- GitHub Actions 使用 macOS runner 执行 Apple 签名；签名失败则不发布安装文件。

## 不能由 GitHub runner 替代的测试

- 在你的 MacBook 上，执行快捷指令后，系统“充电上限”是否真的改变。
- 锁屏、睡眠唤醒、重新登录时，用户会话内的自动化是否获得足够权限。
- 充电器、充电速度、温度与电池健康状态下，21:00 到 23:30 能否补到足够电量。

## 解释

本项目改变的是**允许充到的最高比例**，不是接管电源适配器，也不会主动放电。21:00 改为 100% 后，需要市电仍然连接，电池才有机会在 23:30 断电前升高。断电后上限保持 100%，外置充电宝可以继续充电。
