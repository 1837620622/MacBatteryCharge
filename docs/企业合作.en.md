# Enterprise cooperation

简体中文 is the source. [简体中文](企业合作.md) · [繁體中文](企業合作.zh-Hant.md) · English

This is for companies and teams. If you're an individual who wants to sponsor the project, see the [sponsorship section](../README.en.md#sponsorship), which is shorter.

## What we can talk about

**Company sponsorship**

Companies can fund development. The sponsorship section of the README can credit your company name and link. The amount and invoicing are arranged separately.

**Custom development**

Adapt the app to your environment. Common requests:

- Bulk deployment: install on a set of Macs with the same starting schedule, instead of setting each one by hand.
- Internal policies: different charging rules for different departments or roles, for example meeting-room machines versus reception machines.
- Integration with existing systems: report charging state and battery health to your operations or asset-management platform.

Custom work can be licensed separately, and you don't have to open-source your internal changes. GPL-3.0 only requires publishing the source when you redistribute this software. Internal use doesn't require publishing your changes.

**Technical support**

Set up charging policies across a team of Macs, and answer questions about deployment and permissions, including:

- Permissions and audit questions for the discharge helper in an enterprise setting.
- What to do when a macOS upgrade changes charge-limit behavior.
- Whether MDM can push these settings.

## How to get in touch

Open an issue at [Issues](https://github.com/1837620622/MacFullBar/issues/new/choose) with the title "Enterprise cooperation". Please include:

- Your company or team name, and roughly how many Macs you have.
- The specific problem you want to solve.
- Any time constraints.

## What we won't do

- Build features that read users' private data. The app only contacts GitHub to check for new versions. It doesn't upload battery data or collect usage habits, and the enterprise version won't add that for statistics.
- Bypass system security mechanisms. The discharge helper runs as root only because writing to the SMC requires it, not to gain other privileges.
- Promise that the battery will always be full before you unplug. Charging speed depends on the power source, temperature, and system policy, so we can only estimate from the history on this Mac.
