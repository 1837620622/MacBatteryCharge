# 企業合作

[简体中文](企业合作.md) · 繁體中文 · [English](企业合作.en.md)

這是給公司和團隊看的。個人使用者想贊助的話，看 [README 的贊助一節](../README.zh-Hant.md#贊助)，那邊更短。

## 能談什麼

**企業贊助**

公司出資支持開發。README 的贊助一節可以署名（公司名稱和連結），金額和開票另外談。

**客製開發**

按你們的環境改這個軟體。常見的有：

- 批量部署：給一批 Mac 統一安裝、統一設定初始時間表，不用一台台點。
- 內部策略：按部門或職位給不同的充電策略，比如會議室的機器和櫃台的機器不一樣。
- 對接現有系統：把充電狀態、健康度回報給你們的維運平台或資產系統。

客製部分可以另外授權，不要求你們把內部改動開源。GPL-3.0 只要求再散布這個軟體時公開原始碼，內部使用不需要公開你們的改動。

**技術支援**

為團隊裡的 Mac 統一設定充電策略，回答部署和權限上的問題，包括：

- 放電幫手在企業環境裡的權限和稽核問題。
- macOS 升級後，充電上限的行為變了怎麼處理。
- MDM 能不能下發這些設定。

## 怎麼聯絡

在 [Issues](https://github.com/1837620622/MacFullBar/issues/new/choose) 裡開一條，標題寫「企業合作」。請說明：

- 公司或團隊名稱，大概多少台 Mac。
- 想解決的具體問題。
- 有沒有時間要求。

## 不做什麼

- 不做要讀取使用者隱私資料的功能。軟體只在查新版本時連到 GitHub，不上傳電池資料，也不收集使用習慣。企業版也不會為了統計去加這些。
- 不做繞過系統安全機制的事。放電幫手要 root，是因為寫 SMC 必須 root，不是為了取得別的權限。
- 不承諾「斷電前一定能充滿」。充電速度受電源、溫度、系統策略影響，只能按這台機器的歷史資料估計。

## 授權

GPL-3.0。企業內部使用不需要額外授權，也不需要公開你們的內部改動。再散布（包括打包進你們的產品發給別人）時，需要按 GPL-3.0 公開原始碼。

需要不適用 GPL 的授權，可以在 Issues 裡提出來，作者再看。
