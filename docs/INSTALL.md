# MacBatteryCharge — 安装及排障

## 安装要求

- Apple 芯片 MacBook，macOS 26.4 或更新版本。
- Apple“快捷指令”应用可用；macOS 默认自带 `/usr/bin/shortcuts`。
- 需要登录当前用户账号，且正常运行快捷指令应用。

## 作息

- 06:00 市电来电，上限改为 80%。
- 21:00 上限改为 100%，开始把电补满。
- 23:30 市电断电，之后用电池写代码。上限仍是 100%，外置充电宝可以继续充电。
- 本工具不主动放电。早上电量若已高于 80%，不会自动降到 80%。

## 安装

1. 在 GitHub Actions / Releases 下载构建**成功**的 `MacBatteryCharge-macOS-Installer.zip`，解压。
2. 双击 `安装.command`。Mac 可能要求确认打开来自互联网的脚本，请检查源码或右键选择打开。不要关闭 SIP，也不要使用 `sudo`。
3. 程序会依次打开 `白天充电上限80.shortcut` 和 `晚间充电上限100.shortcut`。在快捷指令应用里点击“添加快捷指令”，完成后回 Terminal 按回车继续。
4. 程序检查两条快捷指令都已存在，之后才安装定时任务。安装完成会立即按**当前本地时间**运行一次，或可手动点 `立即校准.command` 再执行。
5. 打开“系统设置 → 电池”，确认实际的“充电上限”已按当前时间改变。光有成功日志不能代替这项检查。
6. 在快捷指令应用中关闭旧的 06:30 / 14:30 / 22:30 定时自动化，避免冲突。

## 已安装哪些文件

- `~/Library/Application Support/MacBatteryCharge/charge_sync.sh`
- `~/Library/Application Support/MacBatteryCharge/profile.sh`
- `~/Library/LaunchAgents/com.macbatterycharge.schedule.plist`
- `~/Library/Logs/MacBatteryCharge/output.log` 和 `error.log`

没有安装系统扩展、内核模块或第三方程序。没有对电池执行强制放电。

## 为什么选择 launchd 而不是“时间判断”快捷指令

日程只有 06:00 和 21:00 两个时间点；两个快捷指令分别只执行一个系统动作。任务使用 `StartCalendarInterval`，并设置 `RunAtLoad`。机器睡眠跨过某一触发点后，macOS 通常会在唤醒时补执行；脚本读取实际运行时的 `HHMM` 再选择 80% 或 100%，不依赖被错过的触发器时间。

**例子**：05:59 为 100%；06:00 为 80%；20:59 为 80%；21:00 为 100%。如果睡眠从 20:00 到第二天 07:00，07:00 醒来会设 80%，而不是错误地执行前一晚的 100%。23:30 断电本身不触发任务，此时上限已经是 100%。

## 常见问题

### 工作流签名失败

GitHub runner 无 Apple ID 的环境可能无法签署 `anyone` 共享文件。检查 Actions 内的 `Sign both shortcuts with Apple` 日志，不能将生成的 `.unsigned.shortcut` 当作最终文件使用。

本机可用：打开仓库源码，在 Mac 终端执行 `bash scripts/local_build.command`，本地 `people-who-know-me` 签名，生成 `dist/MacBatteryCharge-macOS-Installer.zip`。该文件只适合本人导入。如果本机签名也失败，可能是系统或 Apple 服务验证问题，需要排查，不能绕过系统签名检查。

### 快捷指令里显示“未知操作”

这是比文件签名更深一层的问题：签名成功不代表内部 AppIntent 能被当前 Mac 版本解释。先检查 Mac 是否满足 26.4+；在快捷指令中创建一条新快捷指令，搜索系统动作“将充电上限设为”，手工建立 `白天充电上限80`（80%，永久）和 `晚间充电上限100`（100%，永久），避免使用“直到明天”之类的临时设置。手工建好的快捷指令同名时可以运行本项目的安装脚本，安装器会直接发现并使用，不依赖模板导入。

### 安装后不生效

1. 双击 `检查状态.command`，确认两条快捷指令存在且 `launchd` 状态正常。
2. 双击 `立即校准.command`，检查日志中 `shortcuts run` 是否报错。
3. 在快捷指令应用中分别手动运行，检查系统设置中对应上限是否变化。
4. 睡眠、关机、锁屏、快捷指令权限或 Apple 系统版本可能影响执行。用户级 `LaunchAgent` 不是在关机时运行的服务，不能保证断电期间自动唤醒充电。

### 23:30 断电时还没满

补电从 21:00 开始。若机器型号大、充电器功率低，或 21:00 之前电量明显低于 80%，2.5 小时仍可能没到 100%。断电后上限保持 100%，把外置充电宝接上即可继续充。不要把补电起点再改回 22:30，那一段通常不够。

### 卸载

运行 `卸载.command`。快捷指令、历史日志和当前电池上限会被保留。若需要恢复 100%，手动运行 `晚间充电上限100`。
