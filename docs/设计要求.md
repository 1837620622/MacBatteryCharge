# 设计要求

充电上限是菜单栏里的电池软件。它按时间段写系统充电上限，按每一段决定低电量模式，并在窗口上排显示这台 Mac 当时的电池和内存。

## 作息

市电每天 06:00 来，23:30 断。23:30 之后开始写代码，自己会再接一个充电宝。23:30 不是软件里的定时任务，软件不负责断电。

默认两段：

| 时间 | 充电上限 | 低电量 |
|---|---|---|
| 06:00–20:59 | 80% | 不用 |
| 21:00–次日 05:59 | 100% | 仅用电池时开 |

21:00 才把上限放开到 100%。从 80% 补到 100% 是慢的那一段，22:30 才放开往往赶不上 23:30。21:00 到 23:30 大约两个半小时。

这些时间可以改。结束早于开始，表示跨过午夜。没有被任何一段盖住的时间按 100%。时间段不能重叠，最多 12 段。上限只能是 80、85、90、95、100。

## 不放电

软件只改充电上限。早上如果电量已经高于 80%，就停在那里，不会为了降到 80% 把电放掉。接通电源但已经充满时，电流可以是 0，这时要显示接通，不要显示成正在充电。

## 低电量

每一段单独选：这段不用、这段一直开、仅用电池时开。默认白天不用，晚上那段仅用电池时开。

系统把电池和电源分成两套开关。只有点「立即应用」，并且和系统现在的值不一样，才弹出 macOS 自己的管理员密码框。密码不经过本软件。到了 06:00 或 21:00 不弹密码；窗口里写「低电量要改，点立即应用」。

## 时间怎么选

用小时和分钟两个下拉，外加一个表盘。不让人自己敲时间文字。

## 菜单栏

登录后自动打开，没有程序坞图标。点菜单栏图标打开或关上窗口。开机拉起时带 `--background`，不弹窗口，也不弹更新框。

菜单栏文字参照 FanBar 的上下排列，省横向宽度：上面一行是这一段的上限，下面一行是充电、放电、接通、电池或无电池。两行画在同一张模板图标里，因为菜单栏按钮不保证显示换行。位置用系统的 `autosaveName` 记住。带刘海的 Mac 上，按住 Command 可以把图标拖到刘海两边。没有公开接口能让软件自己跳进刘海。

关上窗口后软件继续运行。点「退出」后，这次登录不再改上限；勾了登录启动时，下次登录再打开。

打开之后就会按时间段写充电上限。低电量不在这时写，只在「立即应用」。

从磁盘映像里直接打开不能登记登录启动。装进「应用程序」之后，第一次正常打开会写入登录项。写入时不立刻再启动一个进程，避免菜单栏出现两个图标。

## 上排：电池和内存

数字都从这台 Mac 当时读，不写死。

电池来自 `ioreg` 的 AppleSmartBattery 和 `pmset -g therm`：电量、电流、电压、正在充电还是放电还是接通但没有电流、健康度、标称容量、设计容量、满充容量、循环次数、温度、有没有过热放慢充电。顶层字段是 `"键" = 数字`，电池数据内部是 `"键"=数字`，两种都读。`IsCharging` 可以是 Yes、No、1 或 0。

健康度是标称容量相对出厂设计容量的估算，要标明是估算。`MaxCapacity` 一类字段常常是电量百分比，不能把它当成健康度。温度 3000 表示 30.0°C。读不到内置电池时直接写没有电池，台式机不能崩。

内存来自 `hw.memsize` 和 `host_statistics64`：总容量、估算已用、压力。已用按活跃、联动和压缩页估算，不等于活动监视器的同名栏目。压力高并且正在放电时，才把两件事写在一起。不编一个电池优化分数。

建议句子只能从这些读数推出来：健康度低于 85%、循环用掉设计值的大部分、温度达到 40°C、充过热、接近满电还连着电源、内存压力高。

## 下排：设置

时间段表格、下拉和表盘、这一段的低电量、登录后藏在菜单栏、检查更新、再看引导、卸载、退出、立即应用。

窗口是窄的上下列表，不是左右两栏，也不是网页。文字用系统字体。

## 引导动画

第一次正常打开先播六步引导，画在窗口里，不放视频。看完或跳过之后写入 `guideSeen`，下次不再挡。`--background` 不播。

六步是：放进「应用程序」、菜单栏上下两行、按住 Command 拖到刘海两侧、低电量那一次管理员密码、充电上限只在支持的机器上生效、不会把电放掉。

读电池、温度、内存，以及在支持的机器上改充电上限，都不要额外隐私授权。引导里不要求完全磁盘访问、辅助功能、屏幕录制或输入监控。没有一个开关能让普通菜单栏软件变成系统最高权限。改低电量是唯一要管理员密码的动作。

安装包是临时签名，第一次打开如果被系统拦住，在访达里按住 Control 点「打开」。

## 更新和卸载

启动后向 GitHub 发布页查版本。有新版本时，等窗口真正打开并且引导已经结束，再提示。

卸载去掉登录项和本机配置，并删掉「应用程序」里的软件。不把充电上限和低电量改回去。

## 兼容

macOS 11 起可以安装，Apple 芯片和 Intel 各有 PKG 和 DMG。充电上限只在 Apple 芯片、并且系统提供这项能力时生效，目前是 macOS 26.4 及更新版本。不支持时窗口写明，低电量、内存、登录和引导仍然可用。

## 打包

GitHub Actions 编译、跑不碰真机电池的测试，再上传两种芯片的 PKG 和 DMG。安装包里是软件，不是源代码。Actions 上的机器没有 MacBook 电池，不能代替自己点「立即应用」之后看「系统设置 → 电池」。

开发时不在这台正在使用的 Mac 上安装，避免改掉现在的充电上限。
