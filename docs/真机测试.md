# 真机测试

这里记录在真机上到底测过什么。README 里写着“还没有在真机上完整测过”的功能，以这里的记录为准。测完一项，就把结果填进报告模板，并附上机器和系统版本。

## 测试前

- 记下机器：型号、芯片（Apple 芯片或 Intel）、macOS 版本、是否有刘海。
- 记下电源：原装适配器、移动电源，或其他。
- 记下当前时间表：每段的上限、「放电」是否打开、漂移设置。
- 打开「设置」里的「系统」卡片，点「复制诊断」，留一份作为对照。

## 测试项

| 编号 | 测什么 | 怎么测 |
|---|---|---|
| T1 | 原生上限（macOS 26.4 或更新） | 时间表设 80，插电充到 80 附近，记下停在哪个数。 |
| T2 | 续充 | 停住后用电到低于上限 5%，看是否重新开始充。 |
| T3 | 偶尔充满 | 连续观察一天，记录是否充到 100%，发生在什么时候。 |
| T4 | 放电 | 白天段打开「放电」，看是否断开电源降到上限，到达后是否接回。 |
| T5 | 漂移 | 白天段选「掉 5%」，看电量是否在上限和上限减 5 之间反复。 |
| T6 | 断电前充满 | 把断电时间设成一小时后，看「今晚」写的预计时间，再记下实际开始充电和充满的时间。 |
| T7 | 睡眠 | 放电时合上盖子，唤醒后看电源是否接回，上限是否和设定一致。 |
| T8 | 退出 | 放电时退出软件，看电源是否接回，上限是否保留。 |
| T9 | 卸载帮手 | 在窗口里卸载，看是否先把电源接回来。 |
| T10 | 在系统设置里改上限 | 改成别的数字，看软件在刷新后是否改回时间表的值。 |
| T11 | 过热 | 只记录温度读数是否合理，不强求触发。 |
| T12 | Intel（如有） | 装帮手，看 BCLM 上限是否生效，卸载后是否恢复。 |
