# 真机测试

这里列的是在真机上要测的项目。README 里写着“没在真机上完整测过”的功能，以这里为准。测完一项，就把方括号打上勾，并写下机器和 macOS 版本。

## 测试前

- 记下机器：型号、芯片（Apple 芯片或 Intel）、macOS 版本、是否有刘海。
- 记下电源：原装适配器、移动电源，或其他。
- 记下当前设置：模式、日常上限、离电目标、默认拔电时间、是否记住习惯。

## 智能模式

- [ ] 平时停在设定的日常上限：接着电源几个小时，电量不超过上限。
- [ ] 离电前备电：把默认拔电时间设在 20 分钟后，电量低于 90% 时，到点前能充到离电目标。记下开始充的时间和拔电的时间。
- [ ] 学习：连续 3 天，每天接着电源满 30 分钟后拔掉，窗口里会说出「你平时大约几点拔电源」。
- [ ] 重新学习：点「重新学习」，学到的时间消失，记录次数归零。
- [ ] 关掉「记住我的充电习惯」：只按默认时间备电，不再说学到的时间。

## 固定模式

- [ ] 时间段按设定的上限走；没排到的时间按 100% 充。
- [ ] 断电前充满：开启后，到设定的断电时间之前，按时间表放开到离电目标。
- [ ] 放电（需要放电帮手）：只在打开「放电」的时间段里，超过上限才用电池放到上限，然后停住。

## 一直充满

- [ ] 接着电源后充到 100%。
- [ ] 过热保护：电池温度 35°C 以上时停在 80%，降到 33°C 以下恢复。这一项不要用加热的方式去测，等温度自然到了再看。

## 临时充满

- [ ] 点「临时充满」后充到 100%，拔掉电源或到下一段时结束。

## 刘海灵动岛（有刘海的 Mac）

- [ ] 第一下点击刘海就展开，第二下收回；展开后「临时充满」「打开窗口」两个按钮有效。
- [ ] 两侧小字开着时，点小字展开灵动岛，而不是打开主窗口。
- [ ] 插拔电源时弹出，几秒后自己收；鼠标停在上面时不收。
- [ ] 关掉「显示灵动岛」后，点刘海没有反应，也不再拦截菜单栏的点击。

## 安装包

- [ ] DMG 挂载后，卷图标是应用图标，「应用程序」快捷方式在。
- [ ] PKG 安装时，欢迎页和左边的应用图标显示；安装完成后，应用在「应用程序」里。
- [ ] 在设置里切换语言（简体、繁體、English），界面和安装器的文字跟着变。

## 更新、帮手和睡眠

- [ ] 设置 → 关于 → 检查更新：有新版本时能打开发布页。
- [ ] 安装和卸载放电帮手，安装时只问一次管理员密码。
- [ ] 睡眠唤醒后，充电上限仍然正确；退出软件后，上限保持原值。

## 结果记录

每一项写下：通过、不通过，或者没测。不通过的，附上现象、发生的时间和机器信息，到 [Issues](https://github.com/1837620622/MacFullBar/issues) 反馈。
