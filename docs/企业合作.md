# 企业合作

简体中文 · [繁體中文](企業合作.zh-Hant.md) · [English](企业合作.en.md)

这是给公司和团队看的。个人用户想赞助的话，看 [README 的赞助一节](../README.md#赞助)，那边更短。

## 能谈什么

**企业赞助**

公司出资支持开发。可以在 README 的「赞助」一节署名（公司名称和链接），金额和开票另外谈。

**定制开发**

按你们的环境改这个软件。常见的有：

- 批量部署：给一批 Mac 统一装、统一设初始时间表，不用一台台点。
- 内部策略：按部门或岗位给不同的充电策略，比如会议室机器和前台机器不一样。
- 对接现有系统：把充电状态、健康度报给你们的运维平台或资产系统。

定制部分可以单独授权，不要求你们把内部改动开源。GPL-3.0 只要求再分发这个软件时公开源码，内部使用不需要公开你们的改动。

**技术支持**

为团队里的 Mac 统一设充电策略，回答部署和权限上的问题，包括：

- 放电帮手在企业环境里的权限和审计问题。
- macOS 升级后充电上限行为变了怎么处理。
- MDM 能不能下发这些设置。

## 怎么联系

在 [Issues](https://github.com/1837620622/MacFullBar/issues/new/choose) 里开一条，标题写「企业合作」。请说明：

- 公司或团队名称，大概多少台 Mac。
- 想解决的具体问题。
- 有没有时间要求。

## 不做什么

- 不做要读取用户隐私数据的功能。软件只在查新版本时访问 GitHub，不上传电池数据，也不收集使用习惯。企业版也不会为了统计去加这些。
- 不做绕过系统安全机制的事。放电帮手要 root，是因为写 SMC 必须 root，不是为了拿到别的权限。
- 不承诺「断电前一定能充满」。充电速度受电源、温度、系统策略影响，只能按这台机器的历史数据估计。

## 许可证

GPL-3.0。企业内部使用不需要额外授权，也不需要公开你们的内部改动。再分发（包括打包进你们的产品发给别人）时，需要按 GPL-3.0 公开源码。

需要不适用 GPL 的授权，可以在 Issues 里提出来，作者再看。
