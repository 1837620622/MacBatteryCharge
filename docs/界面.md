# 界面

布局参照 FanBar 的菜单栏密度，不搬它的风扇控制，也不使用它的代码。FanBar 是另一款软件，许可证是 GPL-3.0。这里只采用它已经公开的排布方式。

## 菜单栏上下两行

FanBar 可以把温度和转速并排，也可以上下叠放，用来省菜单栏宽度。充电上限固定用上下两行：

- 上排：这一段的充电上限，例如 `80%`
- 下排：四个字以内的状态，充电、放电、接通、电池、无电池

左边是模板电池图标。整段做窄，方便在刘海旁边拖动。按住 Command 拖动后，位置由 `autosaveName` 记住。

点图标打开窗口。窗口已经在最前面时再点，就关上。没有程序坞图标。

## 窗口上下两段

窗口窄，大约 420 点宽，内容纵向滚动。

上排标题是「上排」，里面一行一个读数，左边名称，右边数值：

电量、状态、电流、健康、温度、内存、电源、系统上限、这一段、低电量。

下面是从这些读数写出来的短句。

一条分隔线之后是「下排」：时间段表、小时和分钟下拉、表盘、这一段的低电量三选一、登录、更新、引导、卸载、退出、立即应用。

低电量三个选项也是上下排列，不是挤在一行里的隐藏开关。

## 引导

第一次打开，窗口先是引导，不是设置。上面一句说明，中间一块动画，下面步骤标题、正文、上一步、跳过、下一步。最后一步的按钮是「开始使用」。

动画六帧对应六步：图标拖进文件夹、菜单栏两行字、图标从刘海底下滑到旁边、系统密码卡片、80% 和 100% 切换、电池停在上限线以上且不再下降。

颜色用系统标签色和分隔线，不另做一套渐变皮肤。
