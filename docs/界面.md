# 界面

布局参照 FanBar 的菜单栏密度，不搬它的风扇控制，也不使用它的代码。FanBar 是另一款软件，许可证是 GPL-3.0。这里只采用它已经公开的排布方式。

## 菜单栏上下两行

FanBar 可以把温度和转速并排，也可以上下叠放，用来省菜单栏宽度。充电上限固定用上下两行：

- 上排：这一段的充电上限，例如 `80%`
- 下排：四个字以内的状态，充电、放电、接通、电池、无电池

左边是模板电池图标。整段做窄，方便在刘海旁边拖动。按住 Command 拖动后，位置由 `autosaveName` 记住。

点图标打开窗口。窗口已经在最前面时再点，就关上。没有程序坞图标。

## 原则

字少。每个标签尽量一行，一句话不超过一行；长一点的说明放进小圆点（点一下弹出），不铺在界面上。颜色用系统色，质感由「外观」决定：纯色、磨砂、玻璃，透明度可调，改动马上生效。

## 窗口上下两段

窗口窄，大约 420 点宽，内容纵向滚动。

顶上是会动的电量盘：液体水面随电量涨落，充电时有气泡，虚线是上限；盘子旁边是状态、一句话、上限那一行；下面一条电流线：电源 → 电脑 ⇄ 电池，有电流的那段圆点在走，旁边写实时瓦数。窗口看得见时每 2 秒读一次，看不见时 30 秒；动画只在窗口看得见时跑，并跟着“减少动态效果”。

两层都能折叠：「上排」「下排」标题是第一层，点一下整排收起，右边留一句摘要（上排：电量、状态、温度；下排：几段、断电时间）。里面的卡片是第二层，各自能收起，状态记在本机。

上排标题是「上排」，里面是两列读数方块：功率（带电流和电压）、温度、健康（带循环次数）、内存、电源、低电量。

下面最多三条短句，警告排前面，再下面是电量曲线：过去 16 小时的实线，和之后几小时的虚线预测，中间一条「现在」竖线。

「下排」：时间表（小时和分钟下拉、表盘、上限、高于上限时放电、这一段的低电量三选一）、放电帮手、智能（断电前充满、过热保护、通知）、外观（质感、透明度、刘海）、系统（登录、更新、关于和作者、引导、卸载、退出）。底部固定「立即应用」。

低电量三个选项用一排分段按钮：不用、一直开、仅电池。

## 刘海灵动岛

黑色面板，上边和刘海平齐，下边两个大圆角，和刘海连成一块。展开后宽约 380 点：左边电量环，右边状态、上限、今晚的计划，下面两个小按钮。弹簧动画，跟着“减少动态效果”。

## 引导

第一次打开，窗口先是引导，不是设置。上面一句说明，中间一块动画，下面步骤标题、正文、上一步、跳过、下一步。最后一步的按钮是「开始使用」。

动画六帧对应六步：图标拖进文件夹、菜单栏两行字、图标从刘海底下滑到旁边、系统密码卡片、80% 和 100% 切换、电量从 92% 放到 80% 然后停住。

颜色用系统标签色和分隔线，不另做一套渐变皮肤。
