# 充电上限

Mac 菜单栏里的电池软件。登录后藏在菜单栏，点图标打开一条窄窗口。上排是当时的电池和内存，下排是时间段。

不使用快捷指令。GitHub Actions 只上传 PKG 和 DMG，安装包里没有源代码。

完整要求见 [docs/设计要求.md](docs/设计要求.md)。窗口怎么排见 [docs/界面.md](docs/界面.md)。

## 默认作息

| 时间 | 充电上限 | 高于上限时 | 低电量 |
|---|---|---|---|
| 06:00–20:59 | 80% | 放电到 80% | 不用 |
| 21:00–次日 05:59 | 100% | 不放电 | 仅用电池时开 |

06:00 来电之后，电量如果高于 80%，接着电源也先用电池放到 80%，然后停住，由电源直接供电。21:00 把上限改成 100%，给 23:30 断电前留出大约两个半小时。23:30 之后如果接上充电宝，上限仍是 100%。23:30 本身不是软件里的定时任务。

时间可以改。结束早于开始表示跨过午夜。空档按 100%。不能重叠。上限只有 80、85、90、95、100。

## 放电

苹果自带的充电上限只会停止充电，接着电源时不会放电。要把电放到 80%，得把电源适配器暂时断开，这要靠一个以 root 运行的「放电帮手」。窗口里点「安装放电帮手」才会装，要一次管理员密码。只支持 Apple 芯片。

帮手的安全规则：最低只放到 20%；睡眠前、软件退出、2 分钟收不到软件的指令，都会自己把电源接回来；只认安装它的那个用户，不联网；高于上限 2% 才开始放，放到上限就停。每一段可以单独关掉放电。不装帮手时，软件只停止充电，不会往下放。

更旧的系统（macOS 26.4 之前）没有系统自带的充电上限，装了帮手后由帮手直接停止充电。

## 菜单栏和刘海

图标右边是上下两行小字，上面是这一段的上限，下面是充电、放电或接通。这样比横着写省地方。带刘海的 Mac 上，按住 Command 把图标拖到刘海两侧，松手后位置会记住。

另有刘海灵动岛：鼠标移到刘海上，或插拔电源时，从刘海里展开电量、上限和今晚的计划，有「临时充满」和「打开窗口」。可以选在刘海两侧常驻小字，没有刘海的屏幕也能虚拟一个。只读鼠标位置，不要任何隐私权限。

## 窗口

上排是读数、建议和电量曲线（过去 16 小时，加上之后几小时的预测）。下排是时间表、放电帮手、聪明一点、刘海和系统。上排、下排和里面的每张卡片都能折叠，收起时右边留一句摘要。

## 断电前充满

默认 23:30 断电。开着「断电前充满」时，软件记下这台机器最近的充电速度，算出最晚什么时候开始充才来得及。21:00 起充来不及，就提前放开到 100%；来得及，就照时间表。窗口上的「今晚」一栏写着预计几点充满。

## 过热保护和临时充满

电池到 40°C 时上限先停在 80%，降到 37°C 以下再按时间表。要出门时点「临时充满」，到下一段开始或者拔掉电源就恢复。

## 低电量

每一段单独选：不用、一直开、仅用电池时开。

只有点「立即应用」，并且和系统现在不一样，才会要一次管理员密码。密码框是 macOS 自己的。到点不会突然弹窗。

## 引导

第一次打开先看六步动画：安装位置、菜单栏两行字、刘海拖动、管理员密码用在哪里、哪些 Mac 能写充电上限、软件不会放电。

读电池和内存不用额外授权。软件不会要求完全磁盘访问或辅助功能。

## 安装

从 [Releases](https://github.com/1837620622/MacBatteryCharge/releases) 按芯片下载。

| 芯片 | 安装包 | 磁盘映像 |
|---|---|---|
| Apple 芯片 | `MacBatteryCharge-3.0.0-arm64.pkg` | `MacBatteryCharge-3.0.0-arm64.dmg` |
| Intel | `MacBatteryCharge-3.0.0-intel.pkg` | `MacBatteryCharge-3.0.0-intel.dmg` |

PKG 装到「应用程序」。DMG 打开后把软件拖进「应用程序」。从磁盘映像里直接打开不会登录自启。

软件没有经过 Apple 公证。第一次打开如果被拦下，打开「系统设置 → 隐私与安全性」，在下面点「仍要打开」。需要 macOS 13 或更新版本。

装好后打开。充电上限会按当前时间段写上，不用等按钮。低电量仍要点「立即应用」，并且只有和系统现在不一样时才要管理员密码。然后打开「系统设置 → 电池」核对。

关上窗口后软件还在菜单栏里。点「退出」后，这次登录不再改上限，下次登录再启动。

充电上限在 Apple 芯片上：macOS 26.4 或更新用系统自带的，更旧的系统装放电帮手后由帮手停充。Intel Mac 仍能看电池、内存、温度，也能设低电量和登录启动，窗口会写明不支持充电上限和放电。台式机没有内置电池时也会直接写出来。

## 卸载

窗口里的「卸载」会去掉登录启动和本机配置，如果装过放电帮手就先把电源接回来再卸掉帮手（要管理员密码），最后删除「应用程序」里的软件。已经设好的充电上限和低电量模式保持不动。

## 更新

窗口打开、引导看完后，每天最多查一次 GitHub 发布。有新版本时窗口顶上出现提示，点「下载并安装」会下载对应芯片的 PKG，校验 SHA-256 后打开安装器，装完自己重新打开。登录时后台启动不查，也不弹窗。

## 开发

用 Swift 和 SwiftUI 写，菜单栏用 AppKit。`Sources/BatteryCore` 是不碰系统的逻辑（时间表、读数解析、充电计划、建议、版本号），有单元测试。`Sources/PowerBridge` 调系统的充电上限接口。`Sources/MacBatteryCharge` 是界面和系统读写。

```bash
swift test                 # 逻辑测试
bash packaging/build.sh    # 测试，编出两种芯片，打 PKG 和 DMG（只打包，不安装）
.build/release/MacBatteryCharge --snapshot snapshots   # 用假数据把窗口画成 PNG
```

Actions 在 macOS 上做同样的事，并把截图作为附件上传。推到 `main` 时自动把 PKG 和 DMG 发布到 Releases。

性能有预算：`MacBatteryCharge --bench` 量读系统、画图标、预测、历史写盘各要几毫秒，Actions 里还让软件空闲 45 秒，看 CPU 和内存。超了就失败。

Actions 上的机器没有 MacBook 电池，不能代替你在自己的电脑上点「立即应用」。
