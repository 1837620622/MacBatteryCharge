# 充电上限

**让电池少受累，离开电源时电量刚刚好。**

充电上限是一个 macOS 菜单栏电池充电上限工具（battery charge limit），适用于 MacBook，Apple 芯片和 Intel 都能用。平时把电池停在 80% 左右，不让它长时间满电（保护电池健康，battery health）；你每天拔电源的时间，它会自己学会，在拔之前把电备足。免费，开源。

## 三种模式

窗口顶上选一个：

| 模式 | 适合谁 | 它做什么 |
|---|---|---|
| **智能**（默认） | 大多数人 | 平时停在你选的上限（80%，可选 85、90、95）。记住你平时几点拔电源，离电前充到你要的量（100%，可选 80、90）。 |
| **固定时间表** | 想自己排时间的人 | 一天分几段，每段停在你选的上限（80、85、90、95、100）。没排到的时间按 100% 充。每段还能打开「放电」（要装放电帮手）。可以选「拔电源前充满」。 |
| **一直充满** | 台式机，或一直插着用的机器 | 接上电源就充到 100%。 |

三种模式都有过热保护：电池温度到 35°C 时最高停在 80%，降到 33°C 以下再恢复。

## 它怎么记住你的习惯

- 每天第一次接着电源满 30 分钟以上、然后拔掉，就记作一次「离开电源」。白天挪个地方、短暂插拔，不算。
- 同一个半小时里记满 3 次，就能说出「你平时大约几点拔电源」，之后在那个时间前把电备好。
- 记录只存在这台 Mac 上，不上传。想重新学，在智能模式里点「重新学习」。不想让它学，关掉「记住我的充电习惯」，就只按你自己设的时间备电。

## 界面

- **主窗口**：电量、现在在做什么、今晚的计划、电量曲线（过去 16 小时的实线，和之后 8 小时的虚线预测）、三种模式、临时充满。
- **设置**（右上角齿轮）：语言（简体中文、繁體中文、English，默认跟随系统）、登录时打开、通知、外观、刘海灵动岛、高级（放电帮手、今天不放电）、关于。
- **刘海灵动岛**（有刘海的 Mac）：点一下刘海展开，再点一下收回去；插拔电源时会自己弹出来，几秒后收起。没有刘海的 Mac，可以在设置里打开「没有刘海也用」，它会挂在菜单栏正中。

## 安装

到 [Releases](https://github.com/1837620622/MacFullBar/releases) 下载对应芯片的文件：

- Apple 芯片：`MacBatteryCharge-<版本>-arm64.dmg` 或 `.pkg`
- Intel：`MacBatteryCharge-<版本>-intel.dmg` 或 `.pkg`

DMG 打开后，把「充电上限」拖进「应用程序」。PKG 会带你走一遍安装，装进「应用程序」。

软件没有经过 Apple 公证。第一次打开被系统拦下时，到「系统设置 → 隐私与安全性」，点「仍要打开」。

## 更新

- 开着的时候，启动后查一次，之后大约每 6 小时查一次。设置里的「自动检查新版本」可以关掉。
- 查到新版本，窗口最上面和设置里都会提示。点「下载新版本」，在浏览器里下载对应芯片的安装包，自己打开安装。点「以后再说」，这一版就不再提示。
- 软件不替你下载，也不替你安装，不要密码。装好以后，正在运行的旧版本会在一两分钟内自己重新打开，设置和数据都保留。
- 用 DMG 覆盖安装后，放电帮手还是旧版本，要在「设置 → 高级」里重新装一次。用 PKG 安装会自己换掉它。

## 反馈问题

「设置 → 关于 → 反馈问题」会在浏览器里打开 GitHub 的新建 issue，标题和诊断信息已经填好：软件版本、系统版本、模式、电量、上限是谁在管、放电帮手和更新的状态，以及最近 120 行日志（用户目录已经换成 `~`）。诊断里没有电池的历史记录，也没有窗口里的内容。内容太长放不进网址时，会复制到剪贴板，你在页面里粘贴就行。

## 权限和隐私

- 读电池和温度：不需要任何授权。
- 设置充电上限：不需要密码。
- 不需要完全磁盘访问、辅助功能、屏幕录制或输入监控。刘海灵动岛只用鼠标位置和点击。
- 不需要账户，不上传电池数据，不收集使用习惯。
- 软件自己的联网只有一件事：查新版本，读 GitHub 上的版本号和下载地址。其余都是你点了，才在浏览器里打开 GitHub 的页面（下载、反馈、项目主页、赞助）。

## 放电帮手（可选）

macOS 自己的充电上限只会停止充电，不会在接着电源时放电。要把电池从 85% 降到 80%，需要暂时断开电源适配器，这要写系统的 SMC，所以要一个 root 权限的小程序。

- 只有固定时间表里你打开「放电」的时间段才会用到它。安装时系统会问一次管理员密码，密码不经过本软件。
- 它只做三件事：断开或接回电源适配器；在没有系统充电上限的 Intel 机器上，用 BCLM 停止充电；报告自己的状态。
- 放电要同时满足：这一段开着「放电」，电池温度读得到，电量高于上限 3% 以上，并且不低于 20%，今天没有点「今天不放电」。放到上限就接回电源。
- 睡眠时不放电，会接回电源。软件退出，或者两分钟没收到软件的指令，它也会自己接回电源。
- 卸载：「设置 → 高级 → 卸载放电帮手」。卸载前会先把电源接回来。

## 说实话的限制

- 离电前备电不是保证。离电时间提前，或者充电变慢（比如换了移动电源），都可能到点还没充满。过热时最高停在 80%，也会充不满。
- 苹果自己的上限不是精确的，会有几个百分点的误差，偶尔也会充到 100%。软件阻止不了这一点。
- 温度来自系统的电池传感器，和系统里显示的可能略有出入。35°C 和 33°C 是我们选的保守值，苹果公布的是环境温度 10–35°C。
- 我们在 CI 里能编译、跑测试、打包、生成截图，但不能替你在每一台真机上测。请在自己的 Mac 上试一下，遇到问题到 [Issues](https://github.com/1837620622/MacFullBar/issues) 反馈。
