# 充电上限

**让电池少受累，离开电源时电量刚刚好。**

充电上限是一个 macOS 菜单栏小工具。平时把电池停在 80% 左右，不让它长时间满电；你每天拔电源的时间，它会自己学会，在拔之前把电备足。免费，开源。

[English](README.en.md) · [繁體中文](README.zh-Hant.md) · 简体中文

## 三种模式

窗口顶上选一个：

| 模式 | 适合谁 | 它做什么 |
|---|---|---|
| **智能**（默认） | 大多数人 | 平时停在日常上限（80%，可选 85、90、95）。记住你平时几点拔电源，离电前充到目标（100%，可选 80、90）。 |
| **固定** | 想自己排时间的人 | 一天分几段，每段停在你选的上限（80、85、90、95、100）。没排到的时间按 100% 充。可以选「断电前充满」。 |
| **一直充满** | 台式机，或一直插着用的机器 | 接上电源就充到 100%。 |

三种模式都有过热保护：电池偏热（35°C 以上）时最高停在 80%，降到 33°C 以下再恢复。

## 它怎么记住你的习惯

- 每天第一次接着电源满 30 分钟以上、然后拔掉，就记作一次「离开电源」。白天挪个地方、插拔一下，不算。
- 记满 3 次，就能说出「你平时大约几点拔电源」，之后在那个时间前把电备好。
- 记录只存在你这台 Mac 上，不上传。想重新学，点「重新学习」；不想让它学，关掉「记住我的充电习惯」，就只按你设的默认时间备电。

## 界面

- **主窗口**：电量、现在在做什么、三种模式、临时充满。
- **设置**（右上角齿轮）：语言（简体中文、繁體中文、English，默认跟随系统）、登录时打开、通知、外观、刘海灵动岛、高级。
- **刘海灵动岛**（有刘海的 Mac）：点一下刘海展开，再点一下收回去；插拔电源时会自己弹出来，几秒后收起。

## 安装

到 [Releases](https://github.com/1837620622/MacFullBar/releases) 下载对应芯片的文件：

- Apple 芯片：`MacBatteryCharge-<版本>-arm64.dmg` 或 `.pkg`
- Intel：`MacBatteryCharge-<版本>-intel.dmg` 或 `.pkg`

DMG 打开后，把「充电上限」拖进「应用程序」。PKG 会带你走一遍安装，装进「应用程序」。

软件没有经过 Apple 公证。第一次打开被系统拦下时，到「系统设置 → 隐私与安全性」，点「仍要打开」。

## 权限和隐私

- 读电池和温度：不需要任何授权。
- 设置充电上限：不需要密码。
- 不需要完全磁盘访问、辅助功能、屏幕录制或输入监控。刘海灵动岛只用鼠标位置和点击。
- 不需要账户，不上传电池数据，不收集使用习惯。
- 联网只有两件事：检查新版本（默认每天最多一次，设置里可以关），以及你主动去下载。

## 放电帮手（可选）

macOS 自己的充电上限只会停止充电，不会在接着电源时放电。要把电池从 85% 降到 80%，需要暂时断开电源适配器，这要写系统的 SMC，所以要一个 root 权限的小程序。

- 只有固定模式里你打开「放电」的时间段才会用到它。安装时系统会问一次管理员密码，密码不经过本软件。
- 它只断开或接回适配器，不写别的。
- 电量 20% 以下不放；睡眠前一律接回电源；软件退出或者失去联系，也会接回电源。
- 卸载：设置 → 高级 → 卸载放电帮手。

## 说实话的限制

- 离电前备电不是保证。离电时间提前，或者充电变慢（比如换了移动电源），都可能到点还没充满。
- 苹果自己的上限不是精确的，会有几个百分点的误差，偶尔也会充到 100%。软件阻止不了这一点。
- 温度来自系统的电池传感器，和系统里显示的可能略有出入。
- 我们在 CI 里能编译、跑测试、打包，但不能替你在每一台真机上测。请在自己的 Mac 上试一下，遇到问题到 [Issues](https://github.com/1837620622/MacFullBar/issues) 反馈。
