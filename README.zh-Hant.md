# 充電上限

**讓電池少受累，離開電源時電量剛剛好。**

充電上限是一個 macOS 選單欄小工具。平時把電池停在 80% 左右，不讓它長時間滿電；你每天拔電源的時間，它會自己學會，在拔之前把電備足。免費，開源。

[English](README.en.md) · [簡體中文](README.md) · 繁體中文

## 三種模式

視窗頂上選一個：

| 模式 | 適合誰 | 它做什麼 |
|---|---|---|
| **智慧**（預設） | 大多數人 | 平時停在日常上限（80%，可選 85、90、95）。記住你平時幾點拔電源，離電前充到目標（100%，可選 80、90）。 |
| **固定** | 想自己排時間的人 | 一天分幾段，每段停在你選的上限（80、85、90、95、100）。沒排到的時間按 100% 充。可以選「斷電前充滿」。 |
| **一直充滿** | 桌上型電腦，或一直插著用的機器 | 接上電源就充到 100%。 |

三種模式都有過熱保護：電池偏熱（35°C 以上）時最高停在 80%，降到 33°C 以下再恢復。

## 它怎麼記住你的習慣

- 每天第一次接著電源滿 30 分鐘以上、然後拔掉，就記作一次「離開電源」。白天挪個地方、插拔一下，不算。
- 記滿 3 次，就能說出「你平時大約幾點拔電源」，之後在那個時間前把電備好。
- 充電速度也是從你這臺機器上學出來的。學不準的時候，視窗裡會直接寫明。
- 記錄只存在你這臺 Mac 上，不上傳。想重新學，點「重新學習」；不想讓它學，關掉「記住我的充電習慣」，就只按你設的預設時間備電。

## 介面

- **主視窗**：電量、現在在做什麼、三種模式、臨時充滿。
- **設定**（右上角齒輪）：語言（簡體中文、繁體中文、English，預設跟隨系統）、登入時開啟、通知、外觀、劉海靈動島、高階。
- **劉海靈動島**（有劉海的 Mac）：點一下劉海展開，再點一下收回去；插拔電源時會自己彈出來，幾秒後收起。

## 安裝

到 [Releases](https://github.com/1837620622/MacFullBar/releases) 下載對應晶片的檔案：

- Apple 晶片：`MacBatteryCharge-<版本>-arm64.dmg` 或 `.pkg`
- Intel：`MacBatteryCharge-<版本>-intel.dmg` 或 `.pkg`

DMG 開啟後，把「充電上限」拖進「應用程式」。PKG 會帶你走一遍安裝，裝進「應用程式」。

軟體沒有經過 Apple 公證。第一次開啟被系統攔下時，到「系統設定 → 隱私與安全性」，點「仍要開啟」。

## 許可權和隱私

- 讀電池和溫度：不需要任何授權。
- 設定充電上限：不需要密碼。
- 不需要完全磁碟訪問、輔助功能、螢幕錄製或輸入監控。劉海靈動島只用滑鼠位置和點選。
- 不需要賬戶，不上傳電池資料，不收集使用習慣。
- 聯網只有兩件事：檢查新版本（預設每天最多一次，設定裡可以關），以及你主動去下載。

## 放電幫手（可選）

macOS 自己的充電上限只會停止充電，不會在接著電源時放電。要把電池從 85% 降到 80%，需要暫時斷開電源介面卡，這要寫系統的 SMC，所以要一個 root 許可權的小程式。

- 只有固定模式裡你開啟「放電」的時間段才會用到它。安裝時系統會問一次管理員密碼，密碼不經過本軟體。
- 它只斷開或接回介面卡，不寫別的。
- 電量 20% 以下不放；睡眠前一律接回電源；軟體退出或者失去聯絡，也會接回電源。
- 解除安裝：設定 → 高階 → 解除安裝放電幫手。

## 說實話的限制

- 離電前備電不是保證。離電時間提前，或者充電變慢（比如換了移動電源），都可能到點還沒充滿。
- 蘋果自己的上限不是精確的，會有幾個百分點的誤差，偶爾也會充到 100%。軟體阻止不了這一點。
- 溫度來自系統的電池感測器，和系統裡顯示的可能略有出入。
- 我們在 CI 裡能編譯、跑測試、打包，但不能替你在每一臺真機上測。請在自己的 Mac 上試一下，遇到問題到 [Issues](https://github.com/1837620622/MacFullBar/issues) 反饋。

## 開發

```bash
swift test                                              # 邏輯測試，不碰硬體
bash packaging/build.sh                                 # 編譯兩種晶片，打 PKG 和 DMG，並檢查圖示和語言都在
.build/release/MacBatteryCharge --snapshot snapshots    # 用假資料輸出介面截圖
```
