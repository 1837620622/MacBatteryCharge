# 充电上限 3.2.2

这一版修正界面细节：英文界面的时间改用 12 小时制，电量曲线按页面剩下的高度伸缩，首次引导页上下居中。

## 变化

- **英文时间用 12 小时制**（9:00 PM），和时间选择器一致。
- **电量曲线填满剩下的高度。** 一直充满的页面不再留白；英文内容更长时曲线会收到最小高度，不超出窗口。
- **引导页居中。**

## 升级

直接覆盖安装即可，设置保留。覆盖安装 DMG 后，放电帮手要在「设置 → 高级」里重新装一次；PKG 会自己换掉它。

---

## English

Charge Limit 3.2.2 fixes a few interface details. Times in English now use a 12-hour clock (9:00 PM), matching the time pickers. The charge curve fills the space left on the page, so the always-full page no longer has a blank area and English text can't push content off the window. The first-run guide is centred vertically.

## Upgrading

Install over the existing app and your settings are kept. If you install the DMG over the old app, the discharge helper stays on the old version. Reinstall it in Settings → Advanced. The PKG replaces it automatically.
