菜单栏电池软件。上排看电池和内存，下排改时间段。

- 默认 06:00 到 21:00 充电上限 80%，21:00 到次日 06:00 为 100%。只停止继续充电，不把已经高于上限的电放掉。
- 每一段可以单独选低电量。时间用下拉或表盘。
- 菜单栏上下两行显示。带刘海时按住 Command 拖到两侧，位置会记住。
- 第一次打开有引导动画。读电池和内存不用额外授权。改低电量时才要一次管理员密码。
- Apple 芯片和 Intel 各有 PKG、DMG。需要 macOS 11 或更新版本。充电上限需要 Apple 芯片和 macOS 26.4 或更新版本。

安装后打开软件，看完引导，点「立即应用」，再看「系统设置 → 电池」。
